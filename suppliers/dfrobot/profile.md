# DFRobot

## Overview
Open-source hardware manufacturer. Robots, sensors, displays, education.

## API
- Product catalog: https://www.dfrobot.com
- Limited API for some product lines

## Capabilities
- Robot kits (Alphabot, Malibo, etc.)
- Sensors (wide range)
- Displays (LCD, e-paper)
- Motor controllers
- Maker boards (Romeo, etc.)
- Education kits

## MOQ
- Products: 1 piece
- Bulk: negotiated

## Strengths
- Wide product range
- Good documentation
- Romeo ESP32-S3 (robot controller with camera)
- Education focus (good for kits)
- International shipping

## Weaknesses
- Limited API
- Higher prices than Chinese direct
- Some products niche
