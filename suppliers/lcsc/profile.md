# LCSC Electronics

## Overview
Chinese component distributor. 600K+ components, CNY/USD/EUR pricing.

## API
- Official REST API: https://ips.lcsc.com
- Authentication: API key + HMAC
- Docs: https://www.lcsc.com/docs/openapi/index.html
- Apply: https://fat.lcsc.com/agent

## Capabilities
- Component search (keyword, MPN, category, manufacturer)
- Real-time stock, pricing (tiered), lead time
- Datasheet PDFs
- EasyEDA symbol/footprint integration
- Compliance data (ECCN/HTS)

## Pricing
- CNY/USD/EUR/HKD supported
- Tiered pricing (qty breaks)
- Generally cheapest for Chinese components

## MOQ
- Varies by component
- Many parts available single-unit

## Strengths
- Cheapest component pricing
- Huge inventory
- EasyEDA integration (symbol/footprint/3D)
- Real-time stock data

## Weaknesses
- API requires key + HMAC
- Chinese-market focused
- Shipping times to UK
