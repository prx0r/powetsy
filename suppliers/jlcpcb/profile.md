# JLCPCB

## Overview
Automated electronics factory. PCB fabrication, PCBA, 3D printing, stencil.

## API
- Official REST API: https://api.jlcpcb.com
- Authentication: HMAC signature
- Docs: https://api.jlcpcb.com/docs/api-list
- Python client: https://github.com/i2cjak/jlcpcb_api

## Capabilities
- PCB fabrication (2+ layers, from 2 boards)
- SMT assembly (720K+ in-stock components)
- Stencil ($1.53)
- 3D printing (SLA, MJF, SLM, FDM, SLS)
- Component search with real-time pricing/inventory

## Pricing
- PCB: from $2 (2-layer, 5pcs)
- PCBA setup: $8.18
- SMT: ~$0.0016/solder joint (excluding parts)
- Assembly turnaround: 24-48 hours for prototypes

## MOQ
- PCB: 2 boards minimum
- Assembly: 2 boards minimum
- 3D print: 1 piece

## Strengths
- Fastest prototype turnaround
- Integrated component sourcing
- Real-time API for pricing/inventory
- 3D printing workflows

## Weaknesses
- Assembly limited to JLC catalog parts
- No mechanical design service
- No firmware programming
- No final product assembly
