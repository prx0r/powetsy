# Seeed Studio

## Overview
AI hardware partner. Modules, sensors, edge AI, robotics, PCBA, ODM.

## API
- Official API: Limited (file/order oriented)
- Co-Create program: https://www.seeedstudio.com/blog/co-create/
- PCBA service: https://wiki.seeedstudio.com/Service_for_Fusion_PCB/

## Capabilities
- Modules (XIAO, reSpeaker, grove)
- PCBA (1 piece minimum for some services)
- Component sourcing
- Firmware customization (light)
- Logo/packaging customization
- OEM/ODM
- Distribution
- Co-Create: manufacturing + marketing + distribution

## MOQ
- Light customization: 1 piece
- Deeper customization: ~500 units
- Production: varies

## Lead Time
- Application review: 1-2 days
- Manufacturing review: 5-10 days
- Production: 25-60 days

## Strengths
- XIAO ecosystem (tiny, cheap, powerful)
- reSpeaker mic arrays
- Co-Create program (maker → product)
- Open Parts Library (15K+ components)
- International shipping

## Weaknesses
- More file/order-oriented than API
- Limited real-time pricing API
- MOQ for deeper customization
