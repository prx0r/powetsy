# Seeed Studio — API Details

## API
- Limited (file/order oriented)
- Co-Create: https://www.seeedstudio.com/blog/co-create/
- PCBA: https://wiki.seeedstudio.com/Service_for_Fusion_PCB/
- Open Parts Library: 15,000+ components

## Capabilities
- XIAO modules (tiny, cheap, powerful)
- reSpeaker mic arrays
- Grove ecosystem
- PCBA (1 piece minimum for light customization)
- Firmware customization
- OEM/ODM
- Manufacturing (Co-Create program)

## Role in POW
Module supplier + manufacturing endpoint. Bridges XIAO/Grove ecosystem to production.
