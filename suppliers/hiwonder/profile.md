# Hiwonder

## Overview
Robot servos, kits, controllers. Dynamixel-compatible alternatives.

## API
- Product catalog: https://www.hiwonder.com
- Limited API

## Capabilities
- Servos (LX-224, HX-08LC, serial bus controllers)
- Robot kits (TonyPi, MentorPi, JetMax)
- Motor drivers
- ROS-compatible platforms

## MOQ
- Products: 1 piece

## Strengths
- LX-224 servo ($15.99) — good Dynamixel alternative
- Serial bus servos (TTL, daisy-chainable)
- Complete robot kits
- Competitive pricing

## Weaknesses
- Limited API
- Smaller ecosystem than Dynamixel
- Some products have limited documentation
