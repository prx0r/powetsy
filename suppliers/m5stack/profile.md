# M5Stack

## Overview
Modular ESP32 ecosystem. Core modules, displays, sensors, servos, cases.

## API
- Limited web API
- Customization service: https://m5stack.com/customization-form
- Product catalog: https://shop.m5stack.com

## Capabilities
- ESP32 cores (Atom, Stamp, Core, Core2, CoreS3)
- Displays (LCD, e-paper, LED matrix)
- Sensors (ENV, PIR, ToF, IMU)
- Servos and motor controllers
- Grove-style expansion
- Cases and enclosures
- Custom projects (PCB, firmware, enclosure)

## MOQ
- Products: 1 piece
- Custom projects: negotiated

## Strengths
- Extremely modular (stack ecosystem)
- Good documentation
- Fast prototyping
- Custom project service
- Global shipping

## Weaknesses
- Limited API
- Higher component prices than LCSC
- Custom projects require manual process
