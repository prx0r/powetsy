# Waveshare — API Details

## API
- Documentation: https://www.waveshare.com/api-doc.html
- Apply for credentials: required
- Endpoints include:
  - Product catalog
  - Price change feed (by date range)
  - Single-SKU price history (retail + distributor)
  - Real-time pricing

## Key Feature: Price History
Waveshare provides historical SKU prices — this is garden-worthy data.
