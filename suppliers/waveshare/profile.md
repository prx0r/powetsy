# Waveshare

## Overview
SBCs, displays, motor drivers, HATs, cameras.

## API
- Product catalog: https://www.waveshare.com
- Limited API

## Capabilities
- Motor control boards (ST3215 servo board, etc.)
- Displays (LCD, e-paper, OLED)
- SBCs (Orange Pi, Jetson carrier boards)
- Camera modules
- HATs and expansion boards
- Power supplies

## MOQ
- Products: 1 piece

## Strengths
- ST3215 servo control board ($10.60) — used in SO-101
- Good range of displays
- Competitive pricing
- Global shipping

## Weaknesses
- Limited API
- Some products hard to find in catalog
