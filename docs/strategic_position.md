# Strategic Position

> **POW should be infrastructure for the wave of cheap, rapidly instantiated physical-agent products.**

Not the Etsy seller. Not the robot brand. Not the one-shot gadget designer.

The future looks like **thousands of tiny hardware companies** shipping narrow products built from the same cheap Chinese primitives:

* child-focused learning/companion devices
* elder companion/check-in devices
* plant/pet/home agents
* desk agent controllers
* moving cameras
* cheap pan/tilt vision nodes
* home robots
* drones
* ambient lights/speakers
* toy robotics
* smart workshop devices
* agent-connected appliances

Most will be technologically unremarkable. Their edge is:

> **specific use case + branding + software behavior + distribution**

while the hardware underneath is increasingly commodity.

## The durable layer

```text
physical capability
→ known cheap parts
→ compatibility
→ reference architecture
→ manufacturing route
→ historical economics
→ observed demand
```

## Home Physical Compute

```text
compute: N100 boxes, SBCs, local AI, storage/networking
perception: cameras, microphones, radar, environmental sensors
actuation: servos, motors, relays, pumps, lights
mobility: rovers, drones, small arms
interfaces: buttons, displays, speakers, haptics
energy: batteries, charging, solar, UPS
fabrication: 3D print, CNC, PCBA
```

## The repeating hardware pattern

70% of products reduce to:

```text
ESP32 / cheap Linux module
+ camera or mic
+ speaker
+ screen/light
+ 1–2 servos
+ battery/USB-C
```
